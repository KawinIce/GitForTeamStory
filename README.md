## Our Wonderful Story

1. กาลครั้งหนึ่งนานมาแล้ว มีอัศวินผู้กล้าชื่อไนท์ วันหนึ่งเขาพบแผนที่ลึกลับที่บอกตำแหน่งของสมบัติมหาศาลซึ่งซ่อนอยู่ในปราสาทมังกร เขาจึงตัดสินใจออกเดินทางเพื่อตามหาสมบัติในตำนาน  
   ![knight](/img/knight.png)


2. ระหว่างทาง ไนท์ได้พบกับนักสืบผู้ชาญฉลาด ทั้งสองคนร่วมมือกันอ่านแผนที่และค้นหาเส้นทางที่ถูกต้อง พวกเขาต้องผ่านป่าลึกลับและไขปริศนาต่าง ๆ เพื่อเดินทางไปยังปราสาทให้สำเร็จ
   ![detective](/img/detective.png)

3. เมื่อเดินทางมาถึงปราสาท พวกเขาพบมังกรตัวใหญ่กำลังเฝ้าทางเข้า มังกรพ่นไฟข่มขู่ผู้ที่เข้ามาใกล้ ไนท์รู้สึกกลัว แต่เขาก็รวบรวมความกล้าและคิดหาวิธีผ่านมังกรไปโดยไม่ทำร้ายมัน ![dragon](/img/dragon.png)

4. ทันใดนั้น พ่อมดผู้มีเวทมนตร์ก็ปรากฏตัวขึ้นและเสนอความช่วยเหลือเขาร่ายคาถาทำให้มังกรสงบลง พร้อมเปิดประตูลับของปราสาท ไนท์และนักสืบจึงเดินเข้าไปค้นหาห้องเก็บสมบัติได้อย่างปลอดภัย  
   ![treasure chest](/img/wizard.png)

5. ในที่สุด พวกเขาก็พบหีบสมบัติที่เต็มไปด้วยทองคำและอัญมณีล้ำค่า ไนท์ดีใจมาก แต่เขาติดสินใจนำสมบัติบางส่วนกลับไปช่วยเหลือผู้ยากไร้แทนที่จะเก็บไว้ทั้งหมด ![treasure_open](/img/treasure_open.png)

6. หลังจากไนท์และนักสืบค้นพบสมบัติ พวกเขาก็ได้ยินเสียงประหลาดดังมาจากห้องลับ เมื่อเดินเข้าไปก็พบผีเจ้าชายที่เฝ้าสมบัติมานานหลายร้อยปี เจ้าชายเล่าว่าตนไม่สามารถไปสู่สุขคติได้ เพราะยังมีภารกิจที่ทำไม่สำเร็จ ไนท์จึงอาสาช่วยเหลือเจ้าชายเพื่อให้เขาได้พบกับความสงบสุขอีกครั้ง
   ![ghost](/img/ghost.png)   

7. ไนท์และนักสืบช่วยกันค้นหาความจริงจนพบว่า เจ้าชายเคยซ่อนจดหมายสำคัญไว้ในปราสาท จดหมายนั้นเปิดเผยความจริงเกี่ยวกับอดีตของอาณาจักร เมื่อเจ้าชายได้เห็นความจริงถูกเปิดเผย วิญญาณของเขาก็ค่อย ๆ สงบลง ก่อนจากไป เจ้าชายขอบคุณไนท์และมอบอัญมณีวิเศษให้เป็นของขวัญ ไนท์จึงเดินทางกลับบ้านพร้อมเรื่องราวการผจญภัยครั้งใหม่ที่น่าจดจำ
   ![prince](/img/prince.jpg)
